# FitTrack Gym Management System

FitTrack is a PHP and MySQL gym management system for administrators, staff,
and members. It includes membership management, attendance and QR scanning,
training schedules, payroll, payments, feedback, and nutrition tracking.

## Live system

[**Open FitTrack Gym Management System**](https://fittrackgym.infinityfreeapp.com/portal.php)

## Access portals

- [Member portal](https://fittrackgym.infinityfreeapp.com/member/login.php)
- [Staff portal](https://fittrackgym.infinityfreeapp.com/staff/login.php)
- [Admin portal](https://fittrackgym.infinityfreeapp.com/admin/index.php?page=login)

## Technology

- PHP 7.4+
- MySQL/MariaDB
- HTML, CSS, and JavaScript
- InfinityFree hosting
